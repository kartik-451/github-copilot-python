# GitHub Copilot Instructions - Sudoku Flask Project

## Project Overview

This project is a modern Sudoku web application built using Python Flask, HTML, CSS, and JavaScript.

## Coding Standards

- Write clean, readable, and maintainable code.
- Follow Python PEP 8 standards.
- Use meaningful variable and function names.
- Keep functions modular and reusable.
- Add comments for complex logic.

## Application Requirements

- Do not break existing functionality.
- Maintain compatibility with:
  - Difficulty selector
  - Hint system
  - Check puzzle validation
  - Timer
  - Leaderboard
  - Dark mode
  - Responsive design

## Testing

- Any changes should maintain existing pytest tests.
- New functionality should include appropriate testing when possible.

## UI Guidelines

- Keep the interface clean and accessible.
- Ensure mobile and desktop compatibility.
- Maintain readable text in both light and dark themes.

## GitHub Copilot Usage

- Suggest solutions before making major changes.
- Prefer minimal modifications.
- Explain important changes.
- Avoid unnecessary dependencies.
